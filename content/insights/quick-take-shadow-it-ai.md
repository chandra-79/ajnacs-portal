Shadow IT never went away. But for a decade, it was mostly about SaaS applications — employees using Dropbox instead of SharePoint, Slack instead of the corporate messaging system, personal Google Docs instead of the corporate document management tool.

The new shadow IT is more complex: employees pasting company data into ChatGPT, using AI coding assistants with undefined data handling policies, building workflows with AI tools that have not been reviewed for security or compliance.

## Why the new shadow IT is different

**The data risk is higher.** When an employee used a shadow SaaS app, they typically stored documents or communicated through an unapproved channel. Both are risks. The new shadow IT involves pasting proprietary code, customer data, financial projections, and legal documents into third-party AI systems. The data is sent to external systems and may be used to train future models, depending on the vendor's data handling policies.

**The visibility is lower.** An employee using an unapproved SaaS app leaves a trace — a login event, a document in an external storage system, a credit card charge on expenses. An employee using a web-based AI tool leaves almost nothing visible in corporate systems.

**The behavior is normative.** Using ChatGPT has become a normal, accepted part of many professions. Employees who would have hesitated to install unapproved software think nothing of pasting work material into a free web tool. The risk perception is lower than the actual risk.

## Why blanket bans do not work

Banning ChatGPT and similar tools does not stop employees from using them. It stops employees from telling you they are using them. The behavior continues with less transparency and no guidance.

The organizations that address this effectively acknowledge that employees are using AI tools, assess which tools are acceptable for which data categories, provide approved alternatives for use cases with high data sensitivity, and give employees clear guidance rather than vague prohibitions.

## The governance response

Data classification is the starting point. What data can go into which tools? Publicly available information: most tools acceptable. Internal but non-sensitive information: corporate-approved tools with reviewed data policies. Sensitive data (customer PII, financial, legal, code): approved tools only, with enterprise agreements that cover data handling.

The guidance needs to be specific enough to act on. "Use AI tools responsibly" is not guidance. "Do not paste customer data into ChatGPT; use our enterprise Copilot instance which has the appropriate data processing agreement" is guidance.

Shadow IT is always a signal that the approved options are not meeting employee needs. The productive response addresses both the behavior and the underlying gap.
